## Core findings, with evaluation boundaries

- **Same frozen source model, different domains:** CNR-EXT test occupied F1
  0.988692 (19,155 samples) versus PKLot zero-shot 0.788652 (695,695 samples).
  This is domain-shift evidence, not a same-test-set model leaderboard.
- **V2-A on 154,669 fresh-final samples:** accuracy 0.998894 and occupied F1
  0.998912; occupied recall 0.999058, 97 FP and 74 FN.
- **V1 versus V2-A on that same fresh-final set:** UFPR04 occupied recall
  0.859053 → 1.000000. Both precommitted robustness gates passed.

Earlier results, negative findings, candidate comparisons, and error-analysis
limitations remain available and retain their original evaluation context.

## Main limitations

Single-crop classification only: no localization, full-lot detection, or live
CCTV monitoring. Scores are uncalibrated. Site/date/weather associations are
not causal. Fresh final is development-disjoint but had historically received
V1 inference. The terminal result cannot support another model revision.
